# Zenodo deposit guide

1. Make a clean archive containing the manuscript-supporting code, pseudonymised data, tests, environment files, checksums, data dictionary and reproduction instructions.
2. Exclude credentials, private keys, identity mappings, temporary build files and unrelated repository content.
3. Confirm that the consent and ethics determination permit public release of every included trace field.
4. Sign in at https://zenodo.org and choose **New upload**.
5. Upload the archive, select **Dataset** or **Software** as the resource type, add the authors and ORCIDs, licence, keywords, funding and related publication metadata.
6. Reserve a DOI if the manuscript must include it before public release, or publish the record to mint the DOI immediately.
7. Copy the DOI into the manuscript Data Availability statement, title-page note, cover letter and submission system.
8. Create a GitHub release and connect the public repository to Zenodo only if continuing automatic release archiving is desired.

Recommended archive name: `agricultural-edge-iot-research-artifact.zip`.
Recommended licence: choose only after confirming that it is compatible with the dataset consent, third-party dependencies and institutional requirements.
