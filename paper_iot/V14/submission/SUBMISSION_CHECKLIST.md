# Elsevier upload checklist

The master bundle is a transport package. Extract it before using Editorial Manager and upload each item separately.

| File | Suggested item type |
|---|---|
| `Manuscript.pdf` | Manuscript |
| `Elsevier_LaTeX_source.zip` | LaTeX source files |
| `Supplementary_material.pdf` | Supplementary material |
| `Cover_letter.docx` | Cover letter |
| `Highlights.docx` | Highlights |

The LaTeX source ZIP is flat because Elsevier's Editorial Manager does not process LaTeX subfolders. It contains the main and supplementary sources, bibliography, generated numerical macros, tables, figures, plot data, class files and required style files at one directory level.

Before submission, confirm author approval, author order, affiliations, ethics and consent text, funding, competing interests, DOI resolution, exclusive submission and article type.
